06 / MIJIA SMART WATER FLOSSER PRO

App Mijia / Xiaomi Home

O app é opcional para o uso diário. Ele oferece o modo Personalizado, estatísticas de uso e lembretes.

Pareamento

  1. Instale o Mijia / Xiaomi Home pela loja de aplicativos ou use o código QR do manual original.
  2. Abra o app e toque em “+” no canto superior direito.
  3. Siga as instruções para adicionar o aparelho.
  4. Quando o app detectar o irrigador oral, mantenha o botão superior liga/desliga pressionado para parear via Bluetooth.

A interface pode mudar com as atualizações. A foto não especifica por quanto tempo manter o botão pressionado para parear. Este modelo é destinado à China continental; a disponibilidade em outras regiões do app não foi verificada.

O que você pode configurar

  • Modo Personalizado: padrão do fluxo, frequência e pressão.
  • Relatórios: frequência e duração das sessões.
  • Lembretes: horários e dias.
  • Bloqueio para viagem: ativar ou desativar.
Os lembretes por notificação do sistema exigem um gateway Bluetooth compatível. Segundo uma observação no manual, o telefone sozinho não é suficiente para essa função.
