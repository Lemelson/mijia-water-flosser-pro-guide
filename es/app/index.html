06 / MIJIA SMART WATER FLOSSER PRO

Aplicación Mijia / Xiaomi Home

La aplicación no es necesaria para el uso normal. Permite acceder al modo personalizado, las estadísticas y los recordatorios.

Conexión

  1. Instala Mijia / Xiaomi Home desde la tienda de aplicaciones o mediante el código QR del manual original.
  2. Abre la aplicación y pulsa «+» en la esquina superior derecha.
  3. Sigue las instrucciones para añadir el dispositivo.
  4. Cuando la aplicación detecte el irrigador, mantén pulsado el botón superior de encendido para vincularlo por Bluetooth.

La interfaz puede cambiar con las actualizaciones. La foto no indica cuánto tiempo hay que mantener pulsado el botón para vincularlo. Este modelo está destinado al mercado de China continental; aquí no se ha comprobado si está disponible en otras regiones de la aplicación.

Qué puedes configurar

  • Modo personalizado: tipo de flujo, frecuencia y presión.
  • Informes: frecuencia y duración de las sesiones.
  • Recordatorios: hora y días.
  • Bloqueo para viajes: activar y desactivar.
Los recordatorios mediante notificaciones del sistema requieren una pasarela Bluetooth compatible. Según la nota del manual, el teléfono por sí solo no basta para esta función.
