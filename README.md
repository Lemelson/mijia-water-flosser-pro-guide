# Mijia Smart Water Flosser Pro — interactive guide

An independent visual guide for the **Mijia Smart Water Flosser Pro ME0706**, translated from its Chinese printed manual. It covers first use, display and buttons, modes and nozzles, daily use, cleaning, the Mijia app, troubleshooting, safety and the full manual.

**[Open the guide](https://lemelson.github.io/mijia-water-flosser-pro-guide/)** · **[English](https://lemelson.github.io/mijia-water-flosser-pro-guide/en/)**

Languages: Russian, English, Simplified Chinese, Hindi, Spanish, Arabic, French, Ukrainian, Kazakh and Uzbek. Device labels remain in Chinese so they can be matched to the real display.

## Features

- Interactive display simulator, mode comparison, first-use checklist and practice timer.
- Eight readable sections per language, each with a separate URL and pre-rendered text.
- Responsive layout, Arabic right-to-left layout, printable pages and language switching that retains the current section.
- Canonical URLs, language alternates, structured page data and an 80-page sitemap.

## Privacy of published files

Only sanitized document photographs are included. The surroundings were physically removed from the image files; QR codes were covered. All photographs and generated illustrations were re-encoded and stripped of EXIF, GPS, XMP, IPTC and embedded descriptive metadata. Blank warranty fields and printed manufacturer information are part of the manual, not owner details.

Raw photographs, local file paths, prompts, working files, credentials and earlier project history are excluded. This repository starts with a new history and a generic commit email. There is no analytics or remote font loading. Checklist preferences stay in the browser's local storage. GitHub Pages itself operates the hosting service.

## Run locally

This is a static website with no build dependencies:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`. Publishing uses GitHub Pages from the root of the `main` branch.

## Accuracy

The printed manual is the source of operating parameters. AI-restored illustrations are explanatory and may differ in small details; sanitized photos are provided for comparison. The display is a training simulation and does not connect to a device. This is an unofficial guide, not a Xiaomi support website. Verify warranty coverage with the seller outside mainland China.

The source document is manufacturer material. No ownership or license over Xiaomi trademarks or the printed manual is implied. Search indexing is controlled by search engines and may take time after publication.
