06 / MIJIA SMART WATER FLOSSER PRO

Приложение Mijia / Xiaomi Home

Для обычного использования приложение не обязательно. Оно открывает индивидуальный режим, статистику и напоминания.

Подключение

  1. Установите Mijia / Xiaomi Home из магазина приложений или по QR-коду оригинального руководства.
  2. Откройте приложение и нажмите «+» в правом верхнем углу.
  3. Следуйте подсказкам добавления устройства.
  4. Когда приложение обнаружит ирригатор, удерживайте верхнюю кнопку питания для Bluetooth-привязки.

Интерфейс может меняться с обновлениями. На фото длительность удержания для привязки не указана. Эта модель предназначена для рынка материкового Китая; доступность устройства в других регионах приложения здесь не проверена.

Что можно настроить

  • Индивидуальный режим: способ подачи, частота, давление.
  • Отчёты: частота сеансов и их длительность.
  • Напоминания: время и дни.
  • Блокировка в поездке: включение и отключение.
Напоминания через системные уведомления требуют совместимого Bluetooth-шлюза. Одного телефона, по примечанию в руководстве, для этой функции недостаточно.
